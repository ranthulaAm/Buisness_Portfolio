# Global Project Design Rules
- **Apple iOS Design Language**: This project strictly adheres to Apple's Human Interface Guidelines (HIG).
- **Dark Mode**: Use "Elevated Black" (#18181b / zinc-900) as the base background, not pure black, to create depth. Use subtle zinc borders.
- **Typography**: Strictly use `system-ui` (San Francisco on Apple devices) and adhere to Apple's Dynamic Type scale (e.g., Body is 17px/22px).
- **Micro-interactions**: Use smooth, iOS-like transitions (e.g., `active:scale-[0.96]` on buttons).
- **Images**: Ensure portfolio/product images are large, prominent, and use `object-contain` without being constrained into tight aspect ratios.
